三步，开始第一次点名

  1. 1

    下载，解压

    从 GitHub Releases 下载便携版，双击 RandomPicker.exe 就能用。自包含发布，不用装 .NET，也不要管理员权限。

  2. 2

    导入名单

    一个 TXT 文件，一行一个名字。行首的学号、空行、重复名字都会自动清理，记事本存出来的「ANSI」编码也认。

  3. 3

    开始点名

    名字以 0.1 秒一人的速度滚动，按下空格随时定格。插上翻页笔，站在教室最后一排也能控场。

使用说明书

随 机 点 名 第 1 版 · 与 v1.0.0 同步

滚动点名

每 0.1 秒换一个名字，定格瞬间卡片轻微回弹。140 号大字投在白板上，最后一排也看得清。

空格控制

空格键就是开始和停止，翻页笔上的空格同样有效。讲课讲到一半想点人，手不用碰鼠标。

多班级

教几个班就建几个班。左侧边栏列出所有班级，点哪个班就在哪个班点名，名单互不串场。

名单导入

TXT 拖进来就行。UTF-8、UTF-16、GB18030 编码自动识别，「01 张三」「12、李四」的序号自动剥掉。导入时可选新建、覆盖或追加。

数据在本地

名单保存在程序旁边的 data.json，拷走就是备份。没有任何云端，断网也照常用。

免费且开源

代码在 GitHub 上公开，随便看、随便用。发现问题，欢迎提 Issue。

嘘——老师的隐藏玩法

随机点名，当然也有「不那么随机」的时候。滚动的时候做一点小动作，结果就会如你所愿。这个功能，说明书上没有。

  • 打开程序旁边的 unrandom.txt，写一行 A = 王小明
  • 名字滚起来的时候，悄悄按下 A 键
  • 停下来的就是 王小明，界面毫无痕迹
  • 只生效这一次，下一局自动恢复纯随机

鼠标放上去（或点一下），看看被涂掉的部分。
